# 10. 概要 (Overview)

## 1.1 プロダクトコンセプト

**ピクセルズ** は、Web ブラウザで動く **汎用ノノグラム (ピクチャーロジック)** の MVP。

ノノグラム (別名: お絵かきロジック / ピクロス系) は、行/列ごとに与えられた数字ヒント (連続塗り長さ列) をもとに、グリッドの各マスを「塗る」「× をつける」「空のままにする」と論理的に推論し、隠された絵を完成させるパズル。

## 1.2 ジャンル特性

- **シングルプレイヤーの論理パズル** (リアルタイム性は低、完全に思考時間で進む)
- **離散的入力** (連続的な物理操作はなく、マスごとの決定の積み重ね)
- **解の一意性が重要** (論理的に 1 つの解しか得られないパズルでないと "推測でしか解けない" 感が出る)
- **絵の完成という視覚的報酬** (数字パズルだけでなく、解いた結果が絵になる)

## 1.3 ターゲット

- **PC / タブレット / スマホ** のクロスデバイス (詳細: §97)
- 既存ノノグラム経験者 + 初学者の両方
- 1 パズル 5〜30 分でクリアできる難易度から開始 (5×5 は数分、15×15 は 30 分超もあり)

## 1.4 勝利条件 (クリア判定)

**全セルの塗り状態 (filled / empty) が、パズルの正解ビットマップと完全一致したとき** にクリア。
- × マークは補助 (プレイヤー側のメモ) であり、クリア判定には影響しない (× が付いていても空セルとして扱う)。
- クリア時に経過時間 (mm:ss) を表示し、ベストタイムが更新されれば LocalStorage に保存 (§93)。

## 1.5 MVP 範囲 (Round 5 / 12 論点 final)

### 含むもの
- **5×5 / 10×10 / 15×15** の盤面サイズ (スマホは 10×10 まで快適、15×15 は PC+タブレット限定, §97)
- **三値セル状態** (空 / 塗 / ×、形状で区別)
- **手動マニュアルマーク** (タップで完了ヒント数字をグレーアウト, §60)
- **盤面リセット** (Undo の代替)
- **経過時間表示** (フリーモード、ペナルティなし)
- **クリア時演出** (塗られたセルが色変化アニメ、専用カラー絵不要)
- **PWA** (オフライン対応、Cloudflare Pages デプロイ)
- **20 個のパズル** (5×5 を 5 個 + 10×10 を 8 個 + 15×15 を 7 個、§80 + Round 6 で生成)

### 含まないもの (v1.1 以降)
- **Hard モード** (任天堂式の時間ペナルティ + ミス上限)
- **Undo / Redo**
- **ヒント自動グレーアウト** (現在塗りで完成した数字を自動検出)
- **超大盤面** (20×20 / 25×25 / 30×30)
- **カラーノノグラム** (複数色対応)
- **ユーザー作成パズル** (UGC) と共有
- **Canvas 内 ARIA / キーボード a11y** (DOM 部分のみ MVP)
- **マルチプレイ / 協力 / 対戦**
- **オンラインランキング / クラウドセーブ** (LocalStorage のみ)

> 上記の「含まないもの」は §99 (open-questions) に詳細記載。

## 1.6 旧仕様 (旧コード名: マリオピクセル) からの転換

Round 1〜4 で「2D サイドスクロール プラットフォーマー (旧コード名: マリオピクセル)」を仕様策定 + 実装スケルトン + MVP α (旧タグ v0.5.0-mvp-alpha) まで完成させていたが、Round 5 でジャンルを **汎用ノノグラム** に全面転換。任天堂 IP は使用せず独立した Web ピクチャーロジックゲームとして実装する。

転換の判断:
- **流用**: React 19 / Pixi.js v8 / Bun 1.2.0 / Vite 6 / vite-plugin-pwa / Cloudflare Pages の足回り、PWA / オフライン対応、a11y / クロスデバイス基本方針
- **削除** (Round 6 で実施): 旧物理 (整数+subpixel/重力/ジャンプ) / 衝突 (タイル AABB) / プレイヤー entity / 敵 / アイテム / カメラ追従 / bitECS world / SMB1 互換コード一式
- **再設計**: 入力 (移動+ジャンプ → カーソル+塗/×/消)、ステージ (横長マップ → 数字ヒント付きグリッド)、HUD (SCORE/COIN/LIFE/TIME → ベストタイム/経過時間/完成率)

実装の置換は **Round 6** で実施 (本 Round 5 は仕様確定 + docs 全面書き直しに専念)。

## 1.7 想定プレイ体験 (User Story)

1. ユーザーがブラウザで開く → 「TAP TO START」表示
2. タップ → パズル選択画面 (5×5 / 10×10 / 15×15 のサムネイル一覧)
3. パズルを選択 → 盤面が表示、行/列のヒント数字が表示
4. PC: マウス左クリック=塗 / 右クリック=× / 連続ドラッグ可
5. スマホ: モード切替ボタン (塗/×/消) + タップで適用
6. キーボード: 矢印キーでカーソル移動 + Z=塗 / X=× / C=消
7. ヒント数字をタップして手動でグレーアウト (補助)
8. 全セルが正解と一致 → クリア演出 (色変化アニメ) + 経過時間表示 + ベストタイム更新通知
9. 「次のパズル」 or 「パズル選択に戻る」

## 1.8 設計上の制約 (Web ならでは)

| 制約 | 設計方針 |
|---|---|
| ブラウザ自動再生制限 | 初回ユーザー操作 (タップ/キー入力) で AudioContext を resume する (§92)。 |
| タブ非アクティブ時 RAF 停止 | ノノグラムはリアルタイム性低のため影響軽微、復帰時に経過時間タイマーは継続。 |
| 端末性能のばらつき | 描画コストを fallback で段階的に下げる (§91, §95)。 |
| ネットワーク不安定 | 静的アセットは PWA precache、進捗は LocalStorage に保存 (§93)。 |
| 操作系の差異 | マウス / タッチ / キーボード / ゲームパッド (任意)、4 系統を a11y 対応 (§90, §96)。 |

## 1.9 範囲外の明示

- マルチプレイ (協力/対戦)、ユーザー生成パズル (UGC) は MVP 範囲外。アーキテクチャ上は将来拡張可能性を残す (§94)。
- 課金/広告 SDK は範囲外。
- 任天堂 IP / マリオキャラクター / マリオ風アセット は使用しない (汎用ノノグラム)。
