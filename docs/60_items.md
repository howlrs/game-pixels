# 60. アイテムとブロック

## 6.1 アイテム抽選

`?` ブロックの中身は **プレイヤー状態に応じて決定**:

| プレイヤー状態 | 中身 |
|---|---|
| Small | Mushroom (一部のブロックは Coin 固定) |
| Big / Fire | Fire Flower (一部のブロックは Star 固定) |

- ブロックのデータには `force_item` (上書き) を持たせ、データ側で固定可能にする。
- `Star`, `1UP` は通常データで明示配置 (確率抽選はしない)。

## 6.2 アイテムの動き (共通)

### 6.2.1 Mushroom

- 出現: ブロックから上昇 (16 px 上昇、24 frame)、上昇中は当たり判定無効。
- 動作: ±8 subpixel/frame で水平移動。崖は落ちる。壁で反転。
- 取得: AABB 重なりで取得。Small → Big。
- 寿命: 永続 (画面外でデスポーンのみ)。

### 6.2.2 Fire Flower

- 出現: ブロックの上に静止 (出現演出のみ)。
- 動作: 動かない。取得まで残り続ける。
- 取得: Big → Fire。Small が取得した場合は Big にした上で Fire 化 (二段階) または **強制的に Big のみ** (実装選択肢; 本作は後者)。

### 6.2.3 Star (無敵スター)

- 出現: 16 px 上昇後、Mushroom と同様に水平移動 + 重力。
- 特殊: 床に当たると小ジャンプ (反力 -0x40)。これにより自動的に跳ね回る。
- 取得: プレイヤーを **無敵状態 (10 秒)** にする。
- 無敵中: 接触した敵を即座に倒す (得点連鎖は §5.5.1)。Hazard ダメージは無効。落下死は無効化されない。

### 6.2.4 1UP Mushroom

- 緑のキノコ。動きは Mushroom と同じ。取得でライフ +1。

### 6.2.5 Coin (固定)

- ステージに直接配置されるコイン (空中・タイル内)。取得でスコア +200, コイン +1。
- 100 コインで 1UP。
- ブロックから出るコイン: ブロック頭突き時に上方に短くアニメーション (16 frame) して消滅。

## 6.3 ブロックの種類

### 6.3.1 通常レンガ (Brick)

- Small: 頭突きで微小バウンド演出のみ。中身があれば吐き出す。
- Big/Fire: 頭突きで **破壊**。中身があれば吐き出してから破壊。

### 6.3.2 ?ブロック (Question)

- 頭突きでアイテムを吐き出す。1 回のみ使用可能 (使用後は無地ブロックに変化)。
- 連続コインの ?ブロックは内部に "残コイン数 + タイマー" を持つ (古典 SMW の隠しコイン etc; MVP 範囲外)。

### 6.3.3 隠しブロック (Invisible)

- 描画なし。プレイヤーが下から触れたとき (`vy < 0` で AABB 重なり) のみ実体化。
- 中身は固定 (Coin or 1UP)。

### 6.3.4 サポートブロック

- パイプ、土管、ハシゴ、ツタ。物理的には Solid。Up/Down 入力で別動作 (§30 の Pipe entrance)。

## 6.4 頭突きと弾性

```pseudo
on_head_bump(player, block):
    if block is Brick:
        if player.size != Small:
            destroy(block); spawn_brick_pieces()
            score += 50
        else:
            block.bump_offset_y = -4  # 4 px だけ持ち上げる演出
            block.bump_timer = 12
    elif block is Question:
        if block.uses_remaining > 0:
            spawn_item(block.contents)
            block.uses_remaining -= 1
            if block.uses_remaining == 0:
                block.sprite = used_block
        block.bump_offset_y = -4
        block.bump_timer = 12
```

- 頭突きでブロックの上に乗っている敵 (Goomba 等) は **跳ねて倒れる**。これは別の処理: ブロック頭突き時にブロック上の敵を判定して `on_block_bump` イベントを送る。

## 6.5 スコアリング

| イベント | 点数 |
|---|---|
| Goomba 踏み | 100 |
| Koopa 甲羅化 | 100 |
| 甲羅で敵 | 200, 400, 800, 1000, 2000, 4000, 8000, 1UP |
| 空中連続踏み | 同上のテーブル |
| Coin | 200 |
| Mushroom | 1000 |
| Fire Flower | 1000 |
| Star 取得 | 1000 |
| 1UP | 0 (ライフのみ) |
| ゴール (時間ボーナス) | 残り時間 × 50 |
| ゴール (旗下高さ) | 100 / 400 / 800 / 2000 / 5000 |

得点表示は HUD (§91) で更新。

## 6.6 タイマー

- ステージ制限時間: 既定 400 (秒). 1 ゲーム秒 = 24 物理フレーム (古典互換)。
- 100 を切った時点で BGM 加速 (§92)、BGM テンポを 1.25 倍。
- 0 で死亡。

## 6.7 コインアニメーション (描画上のメモ)

- ブロックから出るコインは物理に影響しないパーティクルとして扱う (コリジョン無効)。
- 描画レイヤーの上層で表示する (§91)。

## 6.8 ステージのスポーン上限

- 同時存在アイテム数の上限: 4。
- 上限超過時は新規ブロックからのアイテム出現を遅延させる (キュー方式)。
