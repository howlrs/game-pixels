# 97. レスポンシブ / クロスデバイス

## 17.1 想定デバイス

| クラス | 解像度例 | 入力 |
|---|---|---|
| デスクトップ PC | 1920×1080, 2560×1440 | Keyboard + (Mouse) + (Gamepad) |
| ノート PC | 1366×768 〜 2560×1664 | Keyboard + (Trackpad) + (Gamepad) |
| タブレット (横/縦) | 2048×1536, 2560×1600 | Touch + (Bluetooth キーボード/コントローラ) |
| スマホ (横) | 1920×1080, 2400×1080 | Touch |
| スマホ (縦) | 1080×2400 等 | Touch |

## 17.2 仮想解像度の決定

- 既定: **480×270 px (16:9)**。NES 比だと 256×240 だが、現代の横長スクリーンで自然なレターボックス回避のため 16:9 を主軸にする。
- 縦持ちモードに切り替わる場合は内部解像度も差し替えるか (例: 270×480)、またはレターボックスで対処。本作では **後者** を初期実装、UI で「ステージはステージ。縦は UI/装飾領域として活用」とする。
- ステージサイズ (タイル幅) は内部解像度の倍数で設計するため、設計時に固定する。

## 17.3 スケーリング

- §91.3 と同じく **整数スケール** を基本。
- スマホ縦持ちでステージ視認領域が小さくなりすぎる場合、`scale = 2` を最低保証 (UI を圧縮してでも最低 2 倍に揃える)。

## 17.4 縦/横の判定

```ts
const orientation = matchMedia('(orientation: portrait)').matches ? 'portrait' : 'landscape';
```

- 横持ちはゲームプレイ中心、縦持ちは UI 領域 + 仮想ジョイパッドを上下に配置する。
- 縦持ちでは仮想ジョイパッドを画面下半分に集中、ゲーム画面は上半分。

## 17.5 セーフエリア

- iOS のホームバー、Android のジェスチャ領域を考慮し、`env(safe-area-inset-*)` を CSS で適用。
- 仮想ボタンはセーフエリアの内側に配置。

## 17.6 入力レイアウト

| デバイス | 既定 |
|---|---|
| デスクトップ | キーボード/ゲームパッド優先。Touch UI 非表示。 |
| タブレット | 自動: Touch + キーボード + ゲームパッド検出時のみ表示 |
| スマホ | 仮想ジョイパッド常時表示。ピンチ無効。 |

- 「直近 1.5 秒に Touch 操作があったか」でモード切替を実装 (キー操作中はタッチパネルを薄く非表示)。

## 17.7 入力ヒント

- 操作ガイドは **検出した最後の入力方式** に応じて記号を切替 (キーボード / ゲームパッド / タッチ)。
- 例: ジャンプの説明を "Space" / "A" / "右下ボタン" で切替。

## 17.8 ネットワークと回線

- 配信は CDN 経由を推奨。GZIP/Brotli 必須。
- 4G/LTE で初回 < 5 秒、3G で < 15 秒のロードを目標。
- オフラインプレイは PWA (§94)。

## 17.9 多言語

- UI は i18n リソース (JSON) で多言語対応。
- 日本語と英語を MVP で。
- フォント: Pixel font 1 種 (English) + 日本語 Pixel font (例: 美咲フォント等のライセンス確認の上)。フォールバックは sans-serif。

## 17.10 横スクロールにおける UI 配置

- HUD: 画面上部に固定 (左: スコア/コイン、中央: ステージ名/タイマー、右: ライフ)。
- 縦持ちでは HUD を上に、仮想パッドを下に。
- アスペクト比に応じて HUD のレイアウトを縦伸縮ではなく **左右マージン** に逃がす (内部解像度を変えないため)。

## 17.11 デバイス特有の考慮

| デバイス | 注意 |
|---|---|
| iOS Safari | フルスクリーン非対応 (PWA 経由のみ)。`100vh` の動的問題 |
| Android Chrome | `address bar` の伸縮で viewport 高さが変動 |
| iPad (Pencil) | Pointer Events で stylus を判定し、ゲーム操作には使わせない (誤操作回避) |
| Surface (Pen) | 同上 |
| ゲーミングモニタ高 Hz | 描画補間で滑らかに (§94) |
| 折りたたみスマホ | 中央折り目でジョイパッドが分断されないよう、左/右の片側に集約配置可能なオプション |

## 17.12 画面回転

- ゲームプレイ中の回転は **自動的に内部仮想解像度を選び直す** (アスペクト変更)。
- 物理は影響を受けない (内部解像度のみ表示の話)。

## 17.13 性能ばらつきへの対応

- 起動時に簡易 FPS ベンチ (1 秒、固定アニメ) を走らせ、低スコアなら `display.renderer = 'canvas2d'` に固定。
- ユーザー側で手動切替可能 (§93 の `display.renderer`)。
