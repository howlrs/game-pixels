# 70. カメラ

## 7.1 設計目標

- プレイヤーが見たい先 (進行方向) を見せる。
- 移動感を阻害しない。デッドゾーンと先読みオフセットでシネマティックに。
- スクロール固定 (戻り防止) は古典互換、必要に応じて両方向対応も選択肢。
- クロスデバイス: 横長 (PC) と縦長 (モバイル縦持ち) の両方で破綻しない。

## 7.2 カメラ座標系

- ワールド座標: ステージ全体の絶対座標 (px)。
- カメラ位置: `cam.x`, `cam.y` (ワールド座標, 左上隅)。
- 表示領域: `cam.x ≦ x < cam.x + screen.w`, 同 y。
- ステージ境界: `cam.x ∈ [0, world.w - screen.w]`, `cam.y ∈ [0, world.h - screen.h]` でクランプ。

## 7.3 水平追従

### 7.3.1 デッドゾーン方式

- 画面中央付近に **デッドゾーン (横幅 32 px)** を持つ。
- プレイヤーがデッドゾーンを超えた場合のみカメラを追従。
- 追従速度: プレイヤーの `vx` を超えない範囲で滑らかに追いつく (簡易: 線形補間 `cam.x += (target - cam.x) * 0.25`)。
- 走り中は **先読みオフセット** で進行方向に 32 px ずらした位置をターゲットにする (急停止時の見え方が悪化しないよう減衰)。

### 7.3.2 進行方向別カメラアンカー (SMW 方式の採用)

- プレイヤーが右に進んでいる時は画面左寄り (例: 25%) を目標にカメラを置く。
- 左に進み始めたら、別のアンカー (画面 75% 寄り) に切替。切替は `vx` の符号反転で発火するが、ヒステリシスを持たせる (古典 SMW の "left-locked / right-locked")。
- これによりカメラの "ぐらつき" を抑える。

### 7.3.3 スクロール固定 (右進行のみ, SMB1 互換オプション)

- ステージ属性 `scroll_lock_left = true` の時、`cam.x` は減らない (右にしか進まない)。
- 実装: `cam.x = max(cam.x_prev, cam.x_target)`。
- 縦持ちレイアウトや探索ステージでは無効化する。

## 7.4 垂直追従

- 既定: プレイヤーが地上にいる間は `cam.y` の **目標値** を「現在の地面の上端 y」にロック (古典 SMB1 互換)。
- ただし `cam.y` は目標値に対して **補間係数 0.25** で追従 (§7.7) し、瞬間スナップしない。これにより高い段差に着地した瞬間にカメラが Y 軸でワープして見える現象を防ぐ。
- 大きく上昇 (天井つき長距離ジャンプ) や落下時は `cam.y` を追従。
- ターゲット: プレイヤーの y を画面の 60% 地点に置く (頭打ち回避)。
- 縦持ちレイアウトの場合は **常時垂直追従** モードに切替 (§97)。

## 7.5 シーン特殊カメラ

- ボス戦: 一定領域に **カメラロック** (両方向にスクロール禁止)。
- ステージクリア演出: プレイヤー追従を止め、スクリプト制御に渡す。
- ピット (落下死): プレイヤーが画面下端に達してもカメラは下げない (画面外に消える演出)。

## 7.6 シェイク・ズーム

- ヒットストップ (頭突き、敵撃破時) に **±2 px の微小シェイク 6 frame**。アクセシビリティ設定で無効化可能 (§96)。
- シェイクは `cam.x/y` のクランプ後に加算 → **加算後にもう一度クランプ** する (画面外の黒帯を映さない)。
- ズームは MVP 範囲外。

## 7.7 数値要約

| パラメータ | 既定値 |
|---|---|
| デッドゾーン幅 | 32 px |
| 先読みオフセット (右走行時) | +32 px |
| カメラ補間係数 | 0.25 (1 frame あたり target との差を 1/4 詰める) |
| 垂直しきい値 (上) | プレイヤー y < cam.y + screen.h × 0.4 |
| 垂直しきい値 (下) | プレイヤー y > cam.y + screen.h × 0.6 |
| スクロール上限 | プレイヤー速度上限と同じ |

## 7.8 既知の罠と対策

| 罠 | 対策 |
|---|---|
| 急停止でカメラが行きすぎる | 先読みオフセットを `vx` に応じて段階的に減衰 |
| 反転入力でカメラがぐらつく | アンカー切替にヒステリシス + クールダウン (12 frame) |
| ステージ端でカメラが画面外を映す | ステージ境界クランプ |
| デッドゾーン中に敵がスポーンしない | 敵スポーンはカメラ右端 +16 px (デッドゾーン非依存) |
