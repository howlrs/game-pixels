# 用語集

本リポジトリの全 docs / コード / Issue / PR で使用する用語の **標準表記** を定義する。表記揺れを防ぎ、機械的 grep で誤訳を発見しやすくする。

## ジャンル / プロジェクト

| 標準表記 | 別名 (使わない) | 意味 |
|---|---|---|
| **ノノグラム / Nonogram** | Picross / お絵かきロジック / ピクチャーパズル / Paint by Numbers | パズルジャンルの正式名称 (英語: Nonogram) |
| **ピクチャーロジック** | (同上) | docs での日本語見出しの主表記 |
| **ピクセルズ / pixels** | mario-pixel / マリオピクセル / ピクセルゲーム | 本プロジェクトのコードネーム |
| **GitHub リポ名** | game-pixels (固定) | リポ名はそのまま、ローカルディレクトリも `game-pixels` で統一 (Round 6 で rename) |

## 盤面 / セル

| 標準表記 | 別名 (使わない) | 意味 |
|---|---|---|
| **盤面 / Grid** | ボード / フィールド / マップ | パズル全体の格子 |
| **セル / Cell** | マス / マスメ / square | 1 つのマス |
| **盤面サイズ (W × H)** | (同上) | 列数 × 行数。例: 5×5 は 5 列 5 行、10×10 は 10 列 10 行 |
| **MVP 盤面サイズ** | (同上) | スマホは 5×5〜10×10、PC+タブレットは 5×5〜15×15。15×15 超は v1.1 |
| **セル状態 (空 / 塗 / ×)** | empty / filled / x-marked / unmarked / cross | 三値 enum、§20 で正式定義 |
| **空セル (空 / `'.'`)** | empty / unmarked / blank / 0 | 何もマークされていない初期状態 |
| **塗りセル (塗 / `'#'`)** | filled / on / 1 / colored | プレイヤーが「ここは塗る」と判定したマス |
| **× セル (× / `'x'`)** | x-marked / cross / negative | プレイヤーが「ここは塗らない」と判定したマス (補助マーカー) |

## ヒント

| 標準表記 | 別名 (使わない) | 意味 |
|---|---|---|
| **ヒント / Clue** | 数字 / 数列 / 制約 / hint | 行/列の連続塗り長さ列 (例: `[3, 1, 2]`) |
| **行ヒント / Row Clue** | 横ヒント | i 行目のヒント。例: `rowClues[i] = [4, 2]` |
| **列ヒント / Column Clue** | 縦ヒント | j 列目のヒント。例: `colClues[j] = [1, 1, 3]` |
| **正解ビットマップ / Solution** | 解答 / アンサー / target | パズルの完成形 (0/1 の 2D 配列) |
| **マニュアルマーク / Manual Mark** | グレーアウト / 取り消し線 / 完了マーク | プレイヤーが手動でヒント数字を「消化済」マークする補助機能 |

## パズル

| 標準表記 | 別名 (使わない) | 意味 |
|---|---|---|
| **パズル / Puzzle** | ステージ / レベル / ゲーム | 1 つの問題 (解 1 つを持つ盤面) |
| **パズルセット / Puzzle Pack** | ステージ群 / シリーズ / コレクション | 複数パズルの集合 (MVP は 20 個 1 セット) |
| **解の一意性 (uniqueness)** | (同上) | 1 つの解しか持たないパズルであること。MVP では生成ツール側で保証 |
| **クリア / Clear** | 完成 / Solve | 盤面の塗りセル配置が正解ビットマップと一致した状態 |

## 入力 / 操作

| 標準表記 | 別名 (使わない) | 意味 |
|---|---|---|
| **カーソル / Cursor** | フォーカス / 選択中マス / pointer | 現在操作対象のセル位置 (キーボード操作時に表示) |
| **入力モード (塗 / × / 消)** | mode / brush / tool | スマホ用のモード切替 (PC は左右クリックで自動判定) |
| **塗る / Fill** | 描画 / paint | 空セルを塗り状態にする |
| **× をつける / Mark X** | バツ印 / cross | 空セルを × 状態にする |
| **消す / Erase** | クリア / undo (← 別物) | 塗 or × を空に戻す |
| **盤面リセット / Reset** | クリア (← 別物) / 全消去 | 全セルを空に戻す (パズル開始時に戻る) |
| **Undo (元に戻す)** | (MVP 不採用) | 1 手戻す機能。MVP では実装しない (v1.1) |

## ペナルティ / 進行

| 標準表記 | 別名 (使わない) | 意味 |
|---|---|---|
| **フリーモード / Free Mode** | (MVP 唯一のモード) | ペナルティなし、経過時間表示のみ |
| **Hard モード** | (v1.1 以降) | 任天堂ピクロス式: 塗り間違いで時間ペナルティ加算、最大ミス上限あり |
| **経過時間 / Elapsed Time** | タイマー / 制限時間 (← 別物) | パズル開始からの経過時間 (mm:ss 表示) |

## 演出 / 描画

| 標準表記 | 別名 (使わない) | 意味 |
|---|---|---|
| **クリア時演出 / Clear Animation** | 完成演出 / フィニッシュ | 全マス正解時に塗られたセルが色変化アニメ (専用カラー絵アセット不要) |
| **prefers-reduced-motion** | (CSS Media Query 標準) | 視覚過敏配慮の OS 設定。これが ON なら全演出を簡素化 |
