# 95. パフォーマンス (Round 5: ピクセルズ仕様)

## 15.1 目標

ノノグラム (本作) はリアルタイム性が低いため、旧プラットフォーマー仕様より緩い目標で十分:

| 機種クラス | 目標 |
|---|---|
| ハイエンド PC | 描画 144Hz、操作レスポンス < 16ms、消費 CPU < 10% |
| ミドル PC / 新型 Mac | 描画 60Hz 安定、操作レスポンス < 33ms |
| 中位スマホ (3年落ち程度) | 描画 60Hz 安定、操作レスポンス < 50ms (タッチ含む)、電池消費 妥当 |
| 低位スマホ | 描画 30Hz でも遊べる、操作レスポンス < 100ms |

> ノノグラムは「思考時間 >> 操作時間」のため、フレームレート目標は緩い。重要なのは「タップ → 描画反映」のレイテンシ。

## 15.2 描画コスト見積もり

15×15 盤面で:
- セル: 225 個 (Pixi.js Sprite または Graphics)
- ヒント数字: ~60 個 (Text または BitmapText)
- UI (HUD / モード切替ボタン): React DOM、Pixi.js とは別レイヤ

ドローコール ~300 程度。Pixi.js v8 + WebGPU で **問題なく 60fps** で描画可能。Canvas2D fallback でも余裕。

## 15.3 ホットパス最適化

### 15.3.1 差分描画

- セル変更時は **変更されたセルのみ** Pixi.js Sprite を更新 (全セル再描画は不要)
- Zustand selector を細かく分けて、変更されたセルだけ React → Pixi.js sync

```typescript
// 例: 1 セルだけ変更
useGame.getState().applyToCell(col, row, 'fill');
// → board[row * W + col] のみ変更
// → renderSync は当該 Sprite のテクスチャを差し替えるのみ
```

### 15.3.2 オブジェクトプール (不要)

旧仕様で重要だった「弾 / パーティクルのオブジェクトプール」は本作では不要。動的生成オブジェクトがほぼ存在しない (カーソル + クリア演出パーティクルのみ、後者は v1.1)。

### 15.3.3 整数演算 (不要)

旧仕様の Int32Array SoA + subpixel 演算は本作では不要 (§20.4)。

## 15.4 GC 削減

- ノノグラムでは Hot Path がほぼ存在しない (ユーザー入力時のみ state 変更)
- `new` を避ける必要性は低いが、`useEffect` の dependency 配列で **オブジェクト literal を避ける** 程度の React の一般的な最適化は守る

## 15.5 モバイルの熱と電池

- 既定: WebGPU + 60fps + シェーダ OFF
- アイドル時 (ユーザー操作なしの時間が 5 秒以上) は rAF を 30Hz に降格して電池節約
- Background tab で `visibilitychange` を捕捉してタイマー + 描画を停止

## 15.6 メモリ

- パズル JSON: 1 個 ~1KB (15×15 でも) — 全 20 個でも 20KB
- Pixi.js Sprite + テクスチャ: ~100KB 程度
- セッション全体で <50MB (低位スマホでも余裕)

## 15.7 計測

- 開発時に `performance.measure()` で「タップ → 描画反映」のレイテンシを計測
- HUD オーバーレイで FPS / 入力レイテンシ表示 (debug build のみ)

## 15.8 リグレッション検知

- CI で代表 5 パズルをロードしてヒント表示 + 全マス塗りまでの描画コストを Playwright で計測 (Round 6 で実装)
- frame 時間の percentile を JSON 出力、前回比 +20% で alert

## 15.9 旧仕様との対応

| 旧 §95 (プラットフォーマー) | 新 §95 (ノノグラム) |
|---|---|
| 60Hz 物理ループのバジェット (4ms input + 6ms render + ...) | リアルタイム不要、操作レスポンス重視 |
| ホットパス最適化 (TypedArray SoA / 整数演算) | 不要 (低頻度更新) |
| オブジェクトプール (弾 / パーティクル) | 不要 (動的オブジェクトなし) |
| Coyote Time / Jump Buffer | なし (ジャンプ自体がない) |

旧 §95 の細かい最適化テクニックは本作では不要だが、Pixi.js v8 + WebGPU 既定 / シェーダ OFF / 電池節約 等の **基本方針は流用**。
