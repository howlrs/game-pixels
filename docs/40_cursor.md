# 40. カーソル + 入力モード

## 4.1 カーソルとは

ピクセルズには「プレイヤーキャラクター」は存在しない。代わりに **カーソル** が現在の操作対象セルを示す。

- **キーボード操作時**: カーソル位置 (col, row) が常に表示される (枠で強調)
- **マウス操作時**: ホバー中のセルがカーソル位置 (常時 1 セルだけ強調)
- **タッチ操作時**: タップ直後のセルが一瞬強調されるが、常時表示はしない (画面占有を避ける)

## 4.2 入力モード (3 値)

セル操作には **モード** がある。現在のモードに応じて、セル操作の挙動が決まる:

| モード | 別名 | 挙動 |
|---|---|---|
| **塗 (Fill)** | brush | セルを「空 → 塗」または「× → 塗」に変更 |
| **× (Mark X)** | cross | セルを「空 → ×」または「塗 → ×」に変更 |
| **消 (Erase)** | clear-cell | セルを「塗 → 空」または「× → 空」に変更 |

### モード切替の実装方針

- **PC マウス**: モードという概念は明示的にはユーザーに見せず、左クリック=塗、右クリック=× の自動判定 (内部的にはモードが切り替わっている)。消したい時は **同じ状態に再クリック** (例: 塗ったセルを左クリックすると空に戻る、これは「塗モードのトグル」として扱う) ※
- **スマホタッチ**: 画面下部にモード切替ボタン (3 ボタン: 塗 / × / 消)。現在のモードを強調表示
- **キーボード**: モードレス、キーごとに直接アクション (Z=塗 / X=× / C=消)
- **ゲームパッド** (任意, MVP 範囲外でも可): A=塗 / B=× / X=消

> ※ **同セル再操作の挙動 (Round 5 / Gemini Pro deep 指摘で「トグル仕様」に確定)**:
> - **タップ (PC マウスクリック / スマホタップ)**: 同セルを同じ入力モードで再タップすると **空に戻す (トグル)** とする。Undo なし MVP の救済策として誤タップを即座に取り消せる
> - **ドラッグ (PC マウスドラッグ / スマホタッチドラッグ)**: 「**起点セル属性保証**」方式 — ドラッグ開始時のセル状態 (空 / 塗 / ×) を記録し、ドラッグ中は **同じ起点状態のセルだけに同じ操作を適用** する。例: 空セルから塗ドラッグを開始 → 通過した空セルだけを塗る、既に塗 or × のセルは no-op (上書きしない)。これにより誤って既存の塗 or × を破壊するリスクを排除

## 4.3 カーソル状態 (TypeScript 型)

```typescript
// Round 6 で実装する型定義のドラフト:

export type InputMode = 'fill' | 'mark-x' | 'erase';

export interface Cursor {
  /** 現在位置 (col, row)。盤面外なら null */
  position: { col: number; row: number } | null;
  /** 現在の入力モード (主にスマホ用)。PC は left/right click で自動切替 */
  mode: InputMode;
  /** カーソルが画面に表示されているか (キーボード操作時 true) */
  visible: boolean;
}
```

## 4.4 カーソル移動 (キーボード)

- `←` `→` `↑` `↓`: カーソルを 1 マス移動 (盤面端で停止、ループしない)
- `Home`: 行頭 (col=0) へ
- `End`: 行末 (col=W-1) へ
- `PageUp` / `PageDown`: ±5 行 (大盤面用、5×5 盤では意味なし)

## 4.5 セル操作 (キーボード)

- `Z`: 現在セルを塗る (空 / × → 塗)
- `X`: 現在セルに × をつける (空 / 塗 → ×)
- `C`: 現在セルを消す (塗 / × → 空)
- `Space`: 同上の Z (塗) のショートカット (一般的なノノグラムソフトの慣習)
- `Enter`: 同上の X (×) のショートカット (任意、衝突回避を見て決定)

## 4.6 セル操作 (マウス)

- **左クリック**: 塗る (左ドラッグで連続塗り)
- **右クリック**: × をつける (右ドラッグで連続 ×)
- **左 + ドラッグ + 同じセル状態を保持しているマス通過**: 連続塗 (既に塗ってあるセルは no-op、空セルだけを塗る = "塗りモード継続")
- **右 + ドラッグ + 同じセル状態を保持しているマス通過**: 連続 × (同上)
- **「消す」モードへの切替**: 既に塗ってあるセルを左クリックでトグル (= 空に戻す)、× 済セルを右クリックでトグル (= 空に戻す) — 詳細は §4.2 ※ の方針

## 4.7 セル操作 (タッチ / スマホ)

- **タップ**: 現在の入力モードに従って操作 (塗 / × / 消)
- **長押し**: モード切替メニューを表示 (現在のセルに対して塗/×/消を選択) ※ MVP では未実装、v1.1 検討
- **ピンチイン/アウト**: 大盤面 (15×15) の場合のみズーム (MVP では 15×15 はスマホ非対応のためピンチ無効)
- **2 本指スワイプ**: パン (大盤面用、MVP では非対応)

> モード切替は画面下部の 3 ボタンで明示的に行う (タップ + ボタンでアフォーダンスを高める)。

## 4.8 入力デバウンス / 連打防止

- **マウスドラッグ**: 同一セルを通過した場合は no-op (1 フレーム内の重複処理を避ける)
- **キーボード**: Z / X / C のキーリピート (押しっぱなし) は許可 (連続塗りの代替)
- **タッチ**: 100ms 未満の連続タップは無視 (誤操作防止)
