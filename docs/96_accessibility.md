# 96. アクセシビリティ (a11y)

## 16.1 設計原則

- 「障壁を取り除く」を原則に、**機能は OFF も ON も同等に動作**するよう実装。
- a11y 設定は **競技性に直結しない範囲**で広く提供 (誰でも遊べる)。
- 表現重視のオプション (CRT, Bloom, シェーダ) は別途 §91 表示設定。

## 16.2 視覚

| 機能 | 仕様 |
|---|---|
| 色覚補助 (Daltonization) | プロタノピア / デューテラノピア / トリタノピア に対応するパレット差し替え |
| 高コントラストモード | 背景を一段暗く、敵/アイテムに白縁取り |
| ピクセル拡大 | デフォルトの 1.5 倍 / 2 倍に拡大 (ただし整数倍維持) |
| UI フォントサイズ | 100% / 125% / 150% |
| Reduced Motion | カメラシェイク無効、星演出/エフェクト弱化 |

## 16.3 操作

| 機能 | 仕様 |
|---|---|
| リマップ | 全論理ボタンの再割当て (§90) |
| 同時押し緩和 (sticky keys) | Run と方向キーの同時押しを「順番押し」で受け付ける |
| Coyote Boost | coyote time 6 → 12 frame に倍化 (オプション) |
| Auto Run | Run を常時 ON とみなす |
| Hold to Run / Toggle to Run | トグル可能 |
| ジャンプアシスト | 落下死直前に自動ジャンプを 1 回発動 |
| 速度を 0.7x / 0.5x | 物理 dt を倍に伸ばす (テクスチャ補間も適用) |

> `slow_mode` 採用時の注意: フレーム時間を変更せず、内部物理の処理頻度を半減 (effective dt × 2) する実装にする。決定論を保つため frame_count での進行はそのまま。

## 16.4 聴覚

| 機能 | 仕様 |
|---|---|
| 字幕 | 重要 SE の発生時に画面端にテキスト (§92) |
| BGM/SE 個別ボリューム | 既定設定画面 |
| Mono 出力 | 左右ミックス (片耳聴取者向け) |
| 視覚キュー | 重要な SE と同期して画面エッジが微フラッシュ |

## 16.5 認知

| 機能 | 仕様 |
|---|---|
| チェックポイント | 各ステージ既定で複数 (§80) |
| 死亡ペナルティ低減 | ライフ無制限モード (a11y) |
| 行先矢印 | 進行方向を画面端に矢印表示 |
| HUD 簡略化 | スコア非表示、コインのみ |
| ポーズで自動セーブ | 進行ステージの位置を一時セーブし復帰可能 |

## 16.6 入力

- iOS の VoiceOver / Android の TalkBack 互換: 主メニュー (タイトル/ポーズ) を ARIA で記述、ステージプレイ中は意図的に音声読み上げを抑制。
- スクリーンリーダー検出時に "音声ガイド モード" を提案 (BGM 抑制、テキスト読み上げ強化)。

## 16.7 ラベル/UI

- 全ボタンに `aria-label`。
- 状態変化は `aria-live="polite"` で読み上げ通知 (例: "ライフ -1, 残り 2")。
- フォーカス可視化 (Tab キー操作で OS 標準のフォーカスリング表示)。

## 16.8 設定の保存

- a11y 設定は §93 のセーブに含む。
- "デフォルトに戻す" ボタンを必ず提供。
- 設定画面の最上部に "推奨セット" (例: "色覚補助 + reduced motion") を一括 ON できるプリセット。

## 16.9 参考標準

- WCAG 2.2 AA 準拠を UI に対して目指す (ゲームプレイ画面を除く)。
- W3C "Game Accessibility Guidelines" の Basic レベル全項目を MVP で達成。
