# 96. アクセシビリティ (a11y) (Round 5: ピクセルズ仕様)

## 16.1 設計原則

- 「障壁を取り除く」を原則に、**機能は OFF も ON も同等に動作**するよう実装。
- a11y 設定は **競技性に直結しない範囲**で広く提供 (誰でも遊べる)。
- 表現重視のオプション (CRT, Bloom 等の旧仕様) は本作では使用しない。
- **DOM 部分** (HUD / メニュー / モード切替ボタン / パズル選択画面) は WCAG 2.2 AA 準拠 + キーボード単独完結
- **Canvas 内** (盤面そのものの描画) の ARIA / キーボード a11y は **MVP 範囲外** (Round 5 / Gemini Pro deep 指摘により v1.1 に申し送り)

## 16.2 視覚

| 機能 | 仕様 (MVP) |
|---|---|
| 色覚補助 | 塗 / × は **形状で区別** (色だけに頼らない、§20.2)。色覚多様性配慮済 |
| 高コントラストモード | 背景を一段明るく、塗セルを濃く、× 記号を太く |
| ピクセル拡大 | デフォルトの 1.5 倍 / 2 倍に拡大 (整数倍維持)。盤面サイズに応じて自動 (§70) |
| UI フォントサイズ | 100% / 125% / 150% (DOM ベースなので CSS で実現) |
| Reduced Motion | クリア時カラー演出を簡素化 (`prefers-reduced-motion` を尊重) |

## 16.3 操作

| 機能 | 仕様 (MVP) |
|---|---|
| リマップ | 全論理キー (CursorMove / Fill / MarkX / Erase / Reset) の再割当て (§90.5.2) |
| 同時押し緩和 (sticky keys) | OS 設定を尊重 (本作側で特別処理は不要) |
| マウス代替 | キーボード単独で全操作完結 (DOM 部分のみ) |
| タッチ代替 | モード切替ボタン + タップで全操作完結 |
| ドラッグ無効化オプション | 連続塗りを無効化 (1 タップ = 1 セル、誤操作防止) |
| WCAG タッチターゲット | 44×44px 以上 (§97 / モード切替ボタン / リセットボタン等) |

## 16.4 聴覚

| 機能 | 仕様 |
|---|---|
| 字幕 | 重要 SE 発生時に画面端にテキスト (§92) |
| BGM/SE 個別ボリューム | 既定設定画面 |
| Mono 出力 | 左右ミックス (片耳聴取者向け) |
| 視覚キュー | 重要な SE (クリア / ベストタイム更新) と同期して画面エッジが微フラッシュ |
| 完全 Mute | BGM/SE 全部 OFF でもプレイ可能 (テキスト UI のみで完結) |

## 16.5 認知

| 機能 | 仕様 (MVP) |
|---|---|
| 中断 + 復帰 | 進行盤面を LocalStorage に自動セーブ (§93)、いつでも続きから再開可能 |
| 経過時間表示 OFF | タイマー非表示モード (時間プレッシャー軽減) |
| ヒント補助の手動マーク | §60 の取り消し線。論理推論を補助 |
| 盤面リセット | いつでも最初からやり直し可能 (Undo 不要) |
| ペナルティなし | MVP は Hard モード (ペナあり) を実装しない (§4 確定 B1) |

## 16.6 スクリーンリーダー対応

- iOS の VoiceOver / Android の TalkBack / Windows NVDA の **DOM 部分は ARIA 対応**:
  - パズル選択画面の各ボタン: `aria-label` (例: "ハート、5×5、難易度: 簡単、ベストタイム 1分23秒")
  - HUD: `aria-live="polite"` で「経過時間 1分00秒」「クリア!」等を通知
  - モード切替ボタン: `aria-pressed` で現在モードを示す
- **Canvas 内** (盤面そのもの) の音声読み上げは MVP 範囲外:
  - 理由: Pixi.js (Canvas) はアクセシビリティツリーに乗らない、DOM オーバーレイで擬似的に実装する手段はあるが MVP の枠を超える高難易度 (Gemini Pro deep 指摘)
  - v1.1 で「視覚障害者向け音声ガイドモード」を独立タスクとして検討

## 16.7 ラベル / UI (DOM 部分のみ)

- 全ボタンに `aria-label` (日本語 + 英語のフォールバック)
- 状態変化は `aria-live="polite"` で読み上げ通知
- フォーカス可視化 (Tab キー操作で OS 標準のフォーカスリング表示、CSS で `outline-offset: 2px` 等)
- フォーカストラップ (モーダル / 確認ダイアログ内では Tab がモーダル外に出ない)

## 16.8 設定の保存

- a11y 設定は §93 のセーブに含む (`UserSettings.a11y`)
- "デフォルトに戻す" ボタンを必ず提供
- 設定画面の最上部に "推奨セット" (例: "色覚補助 + reduced motion + 高コントラスト") を一括 ON できるプリセット

## 16.9 参考標準

- WCAG 2.2 AA 準拠を **DOM 部分** (HUD / メニュー / 設定 / パズル選択) に対して目指す
- W3C "Game Accessibility Guidelines" の Basic レベルのうち、ノノグラム関連項目を MVP で達成
- 視覚障害者向け Canvas a11y は v1.1 で独立タスク

## 16.10 旧仕様との対応

| 旧 §96 (プラットフォーマー) | 新 §96 (ノノグラム) |
|---|---|
| Coyote Boost / ジャンプアシスト | なし (ジャンプ自体がない) |
| 速度 0.7x / 0.5x | なし (リアルタイム性なし) |
| ライフ無制限モード | なし (ライフ概念なし) |
| 行先矢印 / HUD 簡略化 | パズル選択画面に集中、ゲーム中は経過時間 + モード表示のみ |
| Auto Run / Hold to Run / Toggle to Run | なし |

旧 §96 のうち a11y の基本方針 (色覚 / Reduced Motion / リマップ / スクリーンリーダー) は流用、ジャンル特有部分は削除。
