# 99. 未決事項 / 旧仕様の整理 (Round 5)

## 19.1 ピクセルズ MVP 未決事項

Round 5 ノノグラム転換後の未決事項:

### 19.1.1 パズル 20 個の絵柄
- 5×5 (5 個): ハート / 星 / 家 / 猫 / リンゴ など (シンプルな図形 + 動物 + 食べ物)
- 10×10 (8 個): 絵としてもう少し複雑、テーマは Round 6 で決定
- 15×15 (7 個): 上級者向け、複雑な図形 + 動物 + 風景
- IP フリー (任天堂 / 既存ゲーム / アニメ等のキャラクター不使用)
- 解の一意性 (uniqueness) を生成ツール側で全パズル確認 (§80.7)

### 19.1.2 BGM
- MVP では BGM 1 種類のみ (パズル選択 / プレイ中 / クリア で同じトラック)
- v1.1 でカテゴリ別 (5×5 用 / 10×10 用 / 15×15 用) に増やすか検討

### 19.1.3 i18n (多言語)
- MVP は **日本語のみ** (UI / パズルタイトル / メタ description)
- v1.1 で英語追加検討 (i18next + react-i18next は既に依存に含まれるため切替容易)

### 19.1.4 オフライン体験の保証
- Service Worker で全パズル precache 済 (§14.10)
- iOS Safari の 7 日無アクセス削除リスクは継続課題 (§13.9)
- ホーム画面追加促進 UI で軽減

### 19.1.5 ペナルティ式 (Hard モード) の実装可能性
- MVP は **フリーモードのみ** (確定 B1)
- v1.1 で Hard モード追加可能性を検討:
  - 1 ミス = +1 分 / 2 ミス = +2 分 / 3 ミス = +4 分
  - 上限ミス回数で **タイムアップ** (途中で諦める扱い)

### 19.1.6 UGC (ユーザー作成パズル)
- MVP 範囲外
- v2.0 以降で:
  - エディタ UI (盤面エディタ + 解の一意性検証)
  - パズル共有 (Cloudflare D1 + Workers + R2 で配信、§14.15.2)
  - ユーザー認証 (Firebase Auth)

### 19.1.7 Canvas 内 a11y (視覚障害者向け音声ガイドモード)
- MVP 範囲外 (§96)
- v1.1 で独立タスクとして検討:
  - 現在のセル位置 / ヒント / 状態を音声読み上げ
  - キーボード単独で全マス操作可能
  - DOM オーバーレイで擬似的に実装

### 19.1.8 Undo / Redo
- MVP 範囲外 (LocalStorage オートセーブとの整合性管理が複雑、Gemini Pro deep 指摘)
- v1.1 で実装検討。実装方針:
  - 1 手ごとに `Operation` を `history` 配列に push
  - Undo で `history.pop()` → 逆操作実行
  - LocalStorage 保存時は `history` も保存 (再起動後 Undo 可能)

### 19.1.9 ヒント自動グレーアウト判定
- MVP 範囲外 (アルゴリズム実装・エッジケース対応の手間、Gemini Pro deep 指摘)
- v1.1 で実装検討:
  - 行/列ごとに「現在の塗り状態」と「ヒント数列」を照合
  - 完成した数字のみグレーアウト (連続塗りが完璧に一致した場合のみ)

### 19.1.10 大盤面 (20×20 / 25×25)
- MVP 範囲外 (5×5 / 10×10 / 15×15 のみ)
- v1.1 で 20×20 を追加検討、Pixi.js でズーム + パン UI 必須

### 19.1.11 カラーノノグラム
- MVP 範囲外 (二値のみ、空 / 塗 / × の三状態)
- v2.0 で複数色対応検討
